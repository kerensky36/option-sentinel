# Implementation Plan: Fix Covered Call Screener — 100-Share Lot Filter

**Branch**: `007-fix-lot-size-filter` | **Date**: 2026-05-14 | **Spec**: [spec.md](spec.md)

## Summary

The covered call screener currently shows positions with any share count, but options
contracts are always 100-share lots. Positions where `shares % 100 != 0` cannot support
a covered call trade. This fix adds a lot-size gate in `run_screener()` and adds a
`contracts` field to `ScreenerResultView` (= `shares // 100`). Two files change:
`src/data/models.py` and `src/services/covered_call_screener.py`. One new unit test file
documents the filter behaviour (TDD).
