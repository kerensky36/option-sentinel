# Implementation Plan: Demo Mode Login

**Branch**: `014-demo-mode-login` | **Date**: 2026-05-22 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `specs/014-demo-mode-login/spec.md`

## Summary

Add a yellow "Try Demo" button to the login page that bypasses Schwab OAuth and enters
a sandboxed demo session with two pre-seeded fake accounts — one with option spread
positions, one with equity/ETF positions and screener results. Demo mode is purely
client-side: a single new backend endpoint injects `demo_mode=true` into sessionStorage,
after which all API calls are intercepted in `fetchWithAuth()` and served from static
data in a new `demo_data.js` module.

## Technical Context

**Language/Version**: Python 3.11 (backend) / Vanilla ES Modules (frontend)
**Primary Dependencies**: FastAPI, Jinja2, Tailwind CSS (CDN), slowapi
**Storage**: sessionStorage only — `demo_mode`, `schwab_selected_account`; no new keys beyond the existing schema
**Testing**: pytest (backend), manual/browser for frontend (no JS test framework currently in project)
**Target Platform**: Cloud-hosted web app (Cloud Run / Firebase Hosting); Chrome / Safari / Firefox
**Project Type**: Web service
**Performance Goals**: Demo entry < 3 s; account switch < 1 s
**Constraints**: CSP nonce required for all inline scripts; no external API calls in demo mode; sessionStorage only (Principle I)
**Scale/Scope**: 1 new backend endpoint, 1 new JS module, modifications to 4 existing files

**New endpoint contract** — `GET /auth/demo-login`:
- Returns `200 text/html`
- Inline script (CSP nonce required): `sessionStorage.setItem('demo_mode', 'true'); window.location.replace('/')`

- No query parameters; no request body; no Schwab credentials consumed

**No changes** to existing `/api/accounts`, `/api/positions/refresh`, or `/api/screener/refresh`
contract shapes — demo intercepts these client-side before any network request is made.

## Key Implementation Details

### `src/auth/router.py` — `/auth/demo-login`

```python
@router.get("/demo-login", response_class=HTMLResponse)
@limiter.limit("30/minute")
async def demo_login(request: Request):
    """Enter demo mode: sets demo_mode flag in sessionStorage, no Schwab OAuth."""
    nonce = getattr(request.state, "csp_nonce", "")
    html = f"""<!DOCTYPE html>
<html>
<head><meta charset="UTF-8"><title>Demo Mode...</title></head>
<body>
<script nonce="{nonce}">
  try {{
    sessionStorage.setItem('demo_mode', 'true');
  }} catch (e) {{
    console.error('Failed to set demo mode:', e);
  }}
  window.location.replace('/');
</script>
<noscript><p>JavaScript is required. <a href="/">Continue</a></p></noscript>
</body>
</html>"""
    return HTMLResponse(content=html, status_code=200)
```

### `frontend/static/js/auth.js` — additions to `fetchWithAuth`

```js
const DEMO_MODE_KEY = 'demo_mode';

export function isDemoMode() {
  return sessionStorage.getItem(DEMO_MODE_KEY) === 'true';
}

export async function fetchWithAuth(url, options = {}) {
  if (isDemoMode()) {
    const { demoResponse } = await import('./demo_data.js');
    return demoResponse(url);
  }
  // ... existing token/401 logic unchanged ...
}
```

`eraseAll()` already calls `sessionStorage.clear()` which removes `demo_mode`. No change needed.

### `frontend/static/js/demo_data.js` — structure

```js
export const DEMO_SPREADS_HASH = 'demo-spreads-0001';
export const DEMO_EQUITY_HASH  = 'demo-equity-0002';

export const DEMO_ACCOUNTS = [
  { hashValue: DEMO_SPREADS_HASH, accountNumber: 'DEMO — Options Spreads' },
  { hashValue: DEMO_EQUITY_HASH,  accountNumber: 'DEMO — Equities & ETFs' },
];

// Payloads: see research.md D-007 for full data
export const DEMO_POSITIONS_SPREADS = [ /* 6 option leg objects */ ];
export const DEMO_POSITIONS_EQUITY  = [ /* 2 covered call objects */ ];
export const DEMO_SCREENER_RESULTS  = [ /* 4 screener row objects */ ];

function _makeResponse(data) {
  return new Response(JSON.stringify(data), {
    status: 200,
    headers: { 'Content-Type': 'application/json' },
  });
}

export function demoResponse(url) {
  const u = new URL(url, window.location.origin);
  const hash = u.searchParams.get('account_hash') || '';

  if (u.pathname === '/api/accounts')
    return _makeResponse(DEMO_ACCOUNTS);
  if (u.pathname === '/api/positions/refresh')
    return _makeResponse(hash === DEMO_EQUITY_HASH ? DEMO_POSITIONS_EQUITY : DEMO_POSITIONS_SPREADS);
  if (u.pathname === '/api/screener/refresh')
    return _makeResponse(hash === DEMO_EQUITY_HASH ? DEMO_SCREENER_RESULTS : []);
  return _makeResponse({ detail: 'Demo mode: endpoint not available' });
}
```
